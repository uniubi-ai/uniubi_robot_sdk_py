# 历史板内手动脚本

这些脚本从旧 `Build/Sdk/Python/examples` 一次性迁入，以保留原有手动检查入口；后续修改仅在本仓库进行。

它们默认按板内 SDK 使用，不提供外部多设备 SN 配置。常规交互与里程计示例优先使用上级目录的 `example_highlevel.py`。

- `highlevel_sdk_console.py`：交互控制台，操作可能获取控制权或执行动作。
- `test_highlevel_odom.py`：板内里程计手动检查，使用前检查脚本参数和当前设备状态。
- `test_highlevel_sdk.py`：高级接口手动检查，默认流程包含短暂获取和释放控制权，不是只读测试。

文件名中的 `test_` 不表示可自动在真实机器人上运行。请阅读脚本后在现场具备接管条件时手动执行，勿将本目录自动加入 CI 的实机测试。
